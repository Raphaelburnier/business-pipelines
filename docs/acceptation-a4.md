# A4 — preuves d’acceptation

Référence : audit d’autonomie du 14 octobre, lot A4 demandé par Raphaël.

- Un verdict global ne valide aucun critère sans constat propre à ce critère.
- Une preuve contient le résultat attendu, la méthode, le motif et un extrait
  contrôlé par le superviseur dans l’arbre revu. Une lecture ne prouve pas un
  parcours navigateur. Les preuves d’une ancienne tentative restent périmées.
- Finance : les chiffres passent par des métriques structurées comparées aux
  valeurs, unités, devises, dates et sources du snapshot figé. Les nombres dans
  le texte libre sont refusés pour éviter une deuxième version incontrôlée.
- Les contraintes et critères sont relus par une session indépendante ; un
  manquement ou une vérification absente bloque la publication du rapport.
- Les rapports historiques restent lisibles. Leur ancien PASS n’est pas promu
  rétroactivement en preuve de fond. La recette native métier appartient à A5.

Vérification : cas adversariaux dans les tests Finance, du planificateur et des
revues moteur ; suites serveur/moteur, typecheck, tests et build du front.
